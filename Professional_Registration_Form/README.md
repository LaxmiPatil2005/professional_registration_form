# CareerConnect — Professional Registration Form

A responsive student/job-seeker profile form built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — form structure and fields
- `style.css` — responsive styling
- `script.js` — validation, progress bar, file checks, and demo confirmation

## Run the project
1. Extract the ZIP file.
2. Open the `Professional_Registration_Form` folder.
3. Double-click `index.html`, or open it in VS Code.
4. Optional: use the VS Code Live Server extension and click **Go Live**.

## Included fields
Personal details; 10th/SSLC; 12th/PUC/diploma; degree; technical skills checkboxes; language checkboxes; projects and experience; career objective; LinkedIn, GitHub, portfolio; resume upload.

## Important
This is a frontend-only demonstration. It validates the form in the browser but does not save or send registration data. A real registration system needs a backend (for example Java/Spring Boot) and a database (for example MySQL), secure server-side validation, authentication, and safe resume storage. Do not collect real applicant data with this demo until a secure backend and privacy policy are in place.
